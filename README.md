# Discord Mriamys Bot 🚀

Многофункциональный бот для Discord-сервера **Mriamys**, объединяющий экономику, развлечения, музыку и автоматизацию администрирования.

## Основные функции

### 💰 Экономика и Магазин VibeCity
- **VibeКоины**: внутренняя валюта сервера, начисляемая за активность в текстовых и голосовых каналах.
- **Магазин предметов**:
  - Временная смена ника участнику на 1 час.
  - Кастомная приписка к нику.
  - Буст получения опыта (XP).
  - Звуковые аудио-эффекты и мемы в голосовой канал.

### 🎮 Игровые комнаты (Threads)
Все мини-игры запускаются в отдельных ветках, чтобы не засорять основной чат:
- **Казино**: классические ставки на коины.
- **Кости и Монетка**: быстрые дуэли с ботом.
- **Викторина**: викторины с переводом вопросов в реальном времени.

### 🎵 Музыкальный плеер
- Проигрывание треков из YouTube и SoundCloud через `yt-dlp` и `ffmpeg`.
- Очередь треков, пауза, пропуск и регулировка громкости.

### ⚙️ Автоматизация и Модерация
- **Welcome Cards**: генерация приветственных баннеров для новых участников через Easy-PIL.
- **Telegram Notifications**: отправка алертов администратору в Telegram о важных событиях.
- Логирование действий модерации и изменений ролей.

## Стек технологий

- Python 3.11+
- discord.py 2.x
- MariaDB / MySQL (`aiomysql`)
- Easy-PIL
- yt-dlp, FFmpeg
- Docker Compose

## Установка и запуск

1. Заполните `.env`:
   ```env
   DISCORD_TOKEN=ваш_токен
   DB_HOST=mariadb
   DB_USER=пользователь
   DB_PASSWORD=пароль
   DB_NAME=база_данных
   TELEGRAM_BOT_TOKEN=токен
   TELEGRAM_ADMIN_ID=id
   ```

2. Запустите сервис:
   ```bash
   docker compose up -d --build
   ```
